# Magic Rampage for AArch64 PortMaster

Open-source adapter and private release recipe for compatible Magic Rampage
7.8.2 and 7.8.7 owner data. Containers are accepted only after package, ABI
and critical-payload validation; proprietary game data is not distributed.
